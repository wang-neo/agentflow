# Rubric: 代码自审（S6 code_self_review）

对 `code_change`（diff + 测试结果）独立审查。

## 判定维度

1. **方案一致性**（0.3）：diff 逐项对照已批准 tech_doc；无超范围改动；无遗漏改动点。
2. **测试**（0.3）：验收标准全部有测试；先红后绿可追溯；边界覆盖（空/极限/非法输入）。
3. **代码质量**（0.2）：无调试残留；错误处理符合方案契约；无明视 bug（空指针/越界/竞态）。
4. **可回滚性**（0.1）：commit 粒度合理、信息清晰；无无关文件混入。
5. **安全**（0.1）：无秘钥硬编码；无新增高危依赖；输入校验符合方案。

## 输出格式

同 `doc_self_review.md` 的固定 JSON。evidence 用 `file:line`。

## 判定规则

- 维度 1/2/3 任一 fail → fail；4/5 单项 fail → needs_fix
- threshold 0.85；on_fail 回 S5 修复
